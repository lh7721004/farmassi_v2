주문하기 페이지
1. 뒤로가기 버튼
2. 배송지 입력 폼
    2-1. 폼 입력 정보
{
받는분,
전화번호,
주소,
상세주소,
요청사항
}

    2-2. 입력 정책
받는분(필수)
- 한글 영문 허용
- 특수 문자 입력 차단
- 숫자 입력 여부 (검토 필요)
주소(필수)
- 상세주소 비어있는 경우 재확인

 3. 주문하기

        주문 확인 폼 예시
         {
            주소,
            수량,
            금액,
          }
