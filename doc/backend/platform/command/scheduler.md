# 스케줄러

프로세스 안에서 도는 주기 작업. 별도 크론이 아니라 API 프로세스에 붙어 있다.

**입금 자동조회** — 기본 5분마다. 다만 매번 거래내역을 부르지 않는다.
뱅크다는 **계좌당 5분 조회 제한**이 있어서, 계좌 정보가 갱신됐을 때만 실제
조회를 부른다. 간격을 5분보다 짧게 두지 말 것.

**공휴일 갱신** — 공공데이터포털 특일 정보에서 받아 [holidays](../../../database/holidays.md) 를 채운다.

주의: 포털이 주는 키는 이미 URL 인코딩돼 있다. httpx 가 `%` 를 한 번 더
인코딩하면 403 이 난다. `unquote()` 로 풀어서 넣는다.

구현: `server-py/app/scheduler.py`
