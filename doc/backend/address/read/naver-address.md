# `POST /rpc/naver-address` — 주소 검색·좌표 변환

이름은 `naver-address` 지만 **속은 카카오다.** 네이버에서 카카오로 옮기면서
프론트 호출부를 고치지 않으려고 이름을 그대로 뒀다.

두 가지 동작이 있다.

- `action:'search'` — 검색어로 주소 후보 목록. 주소 검색을 먼저 하고, 결과가
  5개 미만이면 키워드 검색으로 보탠다. 건물 이름으로 찾는 사람이 있어서다.
- `action:'reverse'` — 좌표로 주소를 되찾는다. 지도에서 찍은 위치를 주소로 바꾼다.

검색어는 여러 형태로 시도한다. `역삼로123` 처럼 붙여 쓴 것을 `역삼로 123` 으로
띄우고, 그래도 안 나오면 번지를 떼고 도로명만으로 찾는다.

**실패 사유를 뭉개지 않는다.** 원래는 전부 '주소 검색에 실패했습니다' 로 돌려줬는데,
그러면 키가 잘못된 건지 카카오에서 서비스가 꺼진 건지 화면에서 알 수가 없다.
지금은 카카오가 준 사유를 읽어 구분해 돌려준다.
